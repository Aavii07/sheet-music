# sheet-music
This is a repo to store many of my custom scores and allow easy sharing of sheet music. This repo contains hand-made arrangements of previously existing songs transcribed and arranged by ear and often times modified in accordance to my own musical tastes.

I only included the scores that either felt the most polished or looked the most interesting here. For the all of my scores (including some messier ones) go here: https://musescore.com/user/34798343
