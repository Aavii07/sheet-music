# sheet-music
This is a repo to store all my custom scores and allow easy sharing of sheet music. This repo contains hand-made arrangements of previously existing songs transcribed by ear and often (particularly in the later arrangements) modified with my own musicial tastes.

I only included the scores that felt the most polished or looked the most interesting here. I also do not want to be storing all my sheet music behind a paywalled service like musescore.com. For the every single one of my scores (including some sloppier ones) go here: https://musescore.com/user/34798343
